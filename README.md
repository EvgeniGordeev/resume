# Resume

https://evgenigordeev.github.io/resume/

`resume.yml` is the source of truth; every other artifact is generated from it.
Run `make` to list the targets.

## Install

```sh
make build
```

That is `brew install yq poppler node pnpm`, `brew install --cask libreoffice`,
`pnpm install`, and `pip3 install python-docx`.
